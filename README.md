# saifandrumaisah-wedding

Wedding website for Saif & Rumaisah: invitation, family tree, blessings wall and RSVP.
Static pages on GitHub Pages; data in Supabase.

## Start here
- Rules for anyone changing the site (human or AI): `AGENTS.md`. Read it first.
- Something is broken, or reveal day, passwords, backups, takedown: `docs/RUNBOOKS.md`.
- How email, the activity log and admin pages work: `docs/OPERATIONS.md`.
- Run the tests: `npm test` (offline, no network).
- Never commit a secret. This repo is public.
